# JAO POTO

Première interface web progressive de JAO POTO.

## Fichiers
- `index.html` : interface principale.
- `manifest.webmanifest` : informations d'installation.
- `sw.js` : cache de base pour une expérience hors ligne.

## Déploiement
Le projet peut être publié comme site statique sur Render :
- New + → Static Site
- Connecter le dépôt `julesamoi/jao-poto`
- Branch : `main`
- Build Command : laisser vide
- Publish Directory : `.`

Cette version est une maquette fonctionnelle d'interface. Elle ne contient pas encore de connexion à un modèle d'intelligence artificielle, de compte utilisateur ni de base de données.
